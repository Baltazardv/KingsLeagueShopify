# ⌚ Kings League Relojes - Tienda Online Oficial

## 📋 Descripción del Proyecto

**Kings League Relojes** es la tienda online oficial de smartwatches de **Kings League Americas**. Este proyecto de e-commerce ofrece relojes inteligentes exclusivos con el branding oficial de Kings League, diseñados para fanáticos del fútbol y la tecnología.

🔗 **Sitio Web**: [kingsleaguerelojes.com](https://kingsleaguerelojes.com/)

- **Experiencia de compra premium** para fanáticos de Kings League

- **Atención al cliente especializada** en productos tecnológicos

## 🔧 Configuración de Desarrollo

### Requisitos Previos
```bash
# Node.js y npm
node >= 14.0.0
npm >= 6.0.0

# Shopify CLI
npm install -g @shopify/cli @shopify/theme
```

### Setup Local
```bash
# Clonar el tema
shopify theme pull --store=kingsleaguerelojes.myshopify.com

# Desarrollo local
shopify theme dev

# Deploy a producción
shopify theme push
```

### Variables de Entorno
```bash
SHOPIFY_STORE_URL=kingsleaguerelojes.myshopify.com
SHOPIFY_ACCESS_TOKEN=your_access_token
GOOGLE_ANALYTICS_ID=GA_TRACKING_ID
FACEBOOK_PIXEL_ID=FB_PIXEL_ID
```
